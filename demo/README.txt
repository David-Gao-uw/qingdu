清读 · 演示原型
================

打开方式
--------
解压后双击 index.html，用 Chrome 或 Edge 打开即可。
不需要安装任何东西，也不需要联网（vendor 文件夹里带了动画库的离线备份，请不要删）。

演示操作
--------
空格        拍照（进入阅读界面，播放分析动画）
→ / ←       逐层调节阅读辅助（共四层）
1 / 2       切换「原文 / 要点」
S           朗读
R 或 Esc    返回相机，重新开始
也可以直接用鼠标拖底部滑块、点按钮。

录屏用：在地址栏的 index.html 后面加上 #auto 再回车，会自动播放一遍完整流程。

修改内容
--------
用 VS Code（或任意文本编辑器）打开 index.html，搜索下面两个名字：

  const DOC     须知原文。每个字符串是一句话。
                句首加 ~       表示次要句（会被缩小、淡化）
                [n:不要]       禁止/否定词（红色）；含有它的句子会变成关键句卡片
                [t:检查前3天]  时间（灰色小标签）
                [i:身份证]     要带的东西（加粗）

  const GROUPS  「要点」页的清单。ref 必须和原文里某个 [n:] [t:] [i:] 的文字完全一致，
                点这一条时才能跳回原文对应的句子。

改完保存，回到浏览器按 F5 刷新即可看到效果。保存时请保持 UTF-8 编码。

已知差异
--------
页面字体按苹果设备设计（苹方、宋体）。Windows 上会自动换成微软雅黑和中易宋体，
效果略有不同。正式演示建议用 Mac 或 iPad 打开。
