# 在 iPad 上运行「清读」

不需要 Mac，不需要开发者账号，也不会过期。全程大约 5 分钟。

## 你需要

- 一台 iPad，系统 **iPadOS 17 或更新**（设置 → 通用 → 关于本机 → iPadOS 版本）
- 收到的压缩包 `qingdu-ipad.zip`

## 第一步：安装 Swift Playgrounds

打开 App Store，搜索 **Swift Playgrounds**（苹果官方，免费，图标是橙色的小鸟），安装。

如果已经装过，请到 App Store 里把它更新到最新版本。

## 第二步：把压缩包存到 iPad 的"文件"里

- **通过 AirDrop 收到的**：iPad 上弹出提示后点「接受」，文件会自动存到"文件"App 的「下载」文件夹。
- **通过微信收到的**：在微信里点开这个文件 → 右上角「···」→「用其他应用打开」→「存储到"文件"」→ 选「我的 iPad」→ 点「存储」。

## 第三步：解压

1. 打开 iPad 自带的 **"文件"** App（蓝色文件夹图标）。
2. 找到 `qingdu-ipad.zip`（AirDrop 的在「下载」里，微信的在刚才选的位置）。
3. **轻点一下**这个 zip，iPad 会自动解压，旁边出现一个同名文件夹。

## 第四步：用 Swift Playgrounds 打开

1. 进入解压出来的文件夹，里面有一个 **「Qingdu」**（图标是 Swift Playgrounds 的小鸟），轻点它。打开后标题会显示为「清读」。
2. 会自动跳到 Swift Playgrounds 并打开工程。左边是代码，**不用管，也不要改**。
3. 如果点了没反应：打开 Swift Playgrounds → 点左上角的「位置」或「浏览」→ 找到刚才的文件夹 → 点「Qingdu」。

## 第五步：运行

1. 点屏幕顶部工具栏里的 **▶︎ 运行**按钮（三角形）。第一次需要编译，等 10～30 秒。
2. 右边会出现 App 界面。点 App 界面上方的 **全屏按钮**（两个斜对角的箭头），App 就会占满整个屏幕，和真 App 一样。
3. 要退出全屏，从屏幕顶部往下轻扫，或点左上角的按钮。

## 第六步：试用

1. 点「看一份示例」，等彩色光晕和"找到 6 项禁止事项"出现。
2. 拖底部滑块，从左拖到右。也可以点滑块两侧的「小」「大」一层一层跳。
3. iPad 上右边是办事清单。可以改检查时间、打勾、点每条右边的放大镜跳回原文。
4. 打开「演示模式」，点「演示：10 秒后弹出提醒」，系统问是否允许通知时点「允许」，等 10 秒看提醒弹出。
5. 点右上角的喇叭听朗读（记得把 iPad 音量调大）。
6. 拿一张纸质须知，点「扫描纸质须知」试一下。系统问是否允许使用相机时点「好」。

## 常见问题

| 遇到的情况 | 怎么办 |
|---|---|
| 点 ▶︎ 后出现红色报错 | 截图发给负责人。先确认 iPadOS 和 Swift Playgrounds 都是最新版 |
| 「扫描纸质须知」是灰色的，点不了 | 这台 iPad 不支持文档扫描，用「从相册选择」代替 |
| 相机打开是黑的，或者没问权限就失败了 | 打开 设置 → 往下找 **Swift Playgrounds** → 打开「相机」 |
| 设置提醒后一直没有弹出 | 设置 → 通知 → **Swift Playgrounds**（或「清读」）→ 打开「允许通知」。如果还是不行，请告诉负责人，这一项我们需要确认 Swift Playgrounds 是否支持 |
| 朗读没有声音 | 调大 iPad 音量；设置 → 辅助功能 → 朗读内容 → 声音 → 中文，确认有普通话语音 |
| 收到新版本 | 在"文件"里删掉旧的 zip 和文件夹，再按第二步到第五步重新来一遍 |
